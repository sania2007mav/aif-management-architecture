# 1c-batch

Пакетные операции с платформой 1С.

## Запуск скриптов

Скрипты: `src/1c-batch/scripts/` (от корня репозитория **1c-batch-main**, где лежит `README.md` и настраивается `.1c-devbase.bat`).

Если рабочий корень — весь каталог **ВасилийУТ_БК**, используй: `.cursor/skills/1c-batch-main/src/1c-batch/scripts/`.

Запускать **из выбранного корня** (относительные пути к XML/EPF тогда от корня проекта):

```bash
.cursor/skills/1c-batch-main/src/1c-batch/scripts/build-epf.bat src/epf/МояОбработка.xml build/МояОбработка.epf
```

Скрипты сами переходят в каталог с `.1c-devbase.bat`, поднимаясь вверх от папки `scripts` — **текущий каталог процесса может быть любым** (удобно для агента и CI), но пути в аргументах должны быть корректны относительно корня репозитория или абсолютные.

## Работа с обработками

### build-epf.bat — сборка обработки из XML

```bat
src/1c-batch/scripts/build-epf.bat <XML_FILE> <OUTPUT_FILE>
```

- `XML_FILE` — корневой XML-файл обработки (указывайте **полное** имя файла, не короткое 8.3 — иначе платформа ищет подкаталоги по «короткому» имени и не находит `Forms/...xml`)
- `OUTPUT_FILE` — путь к результирующему файлу `.epf` или `.erf`

### dump-epf.bat — разборка обработки в XML

```bat
src/1c-batch/scripts/dump-epf.bat <XML_FILE> <EPF_FILE>
```

- `XML_FILE` — корневой XML-файл для выгрузки (папка создастся автоматически)
- `EPF_FILE` — путь к исходной обработке `.epf` или `.erf`

## Работа с конфигурацией

### load-config.bat — загрузка конфигурации из XML

```bat
src/1c-batch/scripts/load-config.bat <XML_DIR> [FILES] [skipdbupdate]
```

- `XML_DIR` — папка с XML-файлами конфигурации
- `FILES` — (опционально) список файлов через запятую для частичной загрузки
- `skipdbupdate` — (опционально) пропустить обновление конфигурации БД

**По умолчанию после загрузки выполняется обновление конфигурации БД.**

Примеры:
```bat
REM Полная загрузка
src/1c-batch/scripts/load-config.bat src/cf

REM Частичная загрузка одного модуля
src/1c-batch/scripts/load-config.bat src/cf "CommonModules/МойМодуль/Ext/Module.bsl"

REM Частичная загрузка нескольких файлов
src/1c-batch/scripts/load-config.bat src/cf "CommonModules/Мод1/Ext/Module.bsl,CommonModules/Мод2/Ext/Module.bsl"
```

### dump-config.bat — выгрузка конфигурации в XML

```bat
src/1c-batch/scripts/dump-config.bat <XML_DIR> [update]
```

- `XML_DIR` — папка для выгрузки
- `update` — (опционально) инкрементальная выгрузка (только изменения)

## Работа с расширениями

```bat

src/1c-batch/scripts/dump-extension.bat <XML_DIR> <EXT_NAME> [update]
```

## Сценарии использования

### Исправить ошибку в обработке

1. Разобрать: `src/1c-batch/scripts/dump-epf.bat src/epf/МояОбработка.xml D:/Исходная.epf`
2. Отредактировать BSL-файлы в `src/epf/МояОбработка/`
3. Собрать: `src/1c-batch/scripts/build-epf.bat src/epf/МояОбработка.xml build/МояОбработка.epf`
4. Проверить: `src/1c-batch/scripts/run-enterprise.bat build/МояОбработка.epf`

### Загрузка изменённого модуля

После редактирования BSL-файла загрузить его в базу:
```bat
src/1c-batch/scripts/load-config.bat src/cf "CommonModules/МойМодуль/Ext/Module.bsl"
```

### Обновить расширение

1. Выгрузить: `src/1c-batch/scripts/dump-extension.bat src/cfe/МоёРасширение МоёРасширение`
2. Внести изменения
3. Загрузить: `src/1c-batch/scripts/load-extension.bat src/cfe/МоёРасширение МоёРасширение`

## Правила использования

**При выгрузке конфигурации или расширения:** если пользователь явно не указал тип выгрузки (полная или инкрементальная), спросить его перед выполнением:
- Полная выгрузка — выгружает все объекты заново
- Инкрементальная (`update`) — выгружает только изменённые объекты (быстрее)

---

## Важно

- Среда агента/CI может **не видеть** установленную у вас платформу 1С (`1cv8.exe`); это не означает, что путь у вас неверный. Сборку подтверждайте **локально** из корня репозитория.
- **Обработки:** первый параметр — XML-файл, второй — выходной файл
- **Конфигурация/расширения:** первый параметр — папка
- При ошибке — код возврата `1`
- Параметры и ключи платформы смотри в `scripts/*.bat`; для обычной работы достаточно примеров команд выше.
