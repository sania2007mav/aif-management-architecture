# АиФ — МСФО-слой поверх «Бухгалтерия для Казахстана»

Расширение конфигурации **`АиФ_МСФО`** для БК 3.0: корректировки МСФО, карта счетов (в т.ч. 8110 → расходы периода), периметр группы, правила ВГО и консолидация по двум юрлицам **без изменения проводок БП**.

## Документация

- **Схема:** https://sania2007mav.github.io/aif-management-architecture/
- **Репозиторий:** https://github.com/sania2007mav/aif-management-architecture

## Исходники расширения

`src/cfe/АиФ_МСФО`

| Объект | Назначение |
|--------|------------|
| Подсистема `АиФ_МСФО` | Раздел UI |
| `АиФ_СтатьиМСФО` | Статьи МСФО |
| `АиФ_ПериметрГруппы` | ЮЛ в консолидации |
| `АиФ_КартаСчетовМСФО` | Счёт БП → статья МСФО |
| `АиФ_ПравилаВГО` | Правила исключения ВГО |
| `АиФ_КорректировкаМСФО` | Документ корректировок |
| `АиФ_ДвиженияМСФО` | Регистр движений |
| `АиФ_МСФОСервер` | Серверные API |
| `АиФ_ПомощникКонсолидации` | Обработка-заготовка |

## База разработки

Файловая ИБ (см. локальный `.1c-devbase.bat` / `.v8-project.json`, не в git):

- Конфигурация: **Бухгалтерия для Казахстана 3.0.70.1**
- Расширение загружено и применено в БД
- Заполнены демо-данные: 4 статьи, 2 ЮЛ в периметре, карта 8110, правило ВГО

## Загрузка расширения

```bat
powershell -NoProfile -File "%USERPROFILE%\.cursor\skills\db-load-xml\scripts\db-load-xml.ps1" ^
  -InfoBasePath "<путь к Base1S>" -UserName "<user>" -Password "<pwd>" ^
  -ConfigDir "src\cfe\АиФ_МСФО" -Mode Full -Extension "АиФ_МСФО" -UpdateDB
```

Протокол встречи и учётные данные в репозиторий не публикуются.
