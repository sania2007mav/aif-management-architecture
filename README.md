# АиФ — МСФО-слой поверх «Бухгалтерия для Казахстана»

Расширение **`АиФ_МСФО`** для БК 3.0: корректировки МСФО, карта счетов, периметр группы, правила ВГО и консолидация **без изменения проводок БП**.

## Статус

Рабочий MVP загружен в Base1S:

- формы справочников / документа / помощника;
- заполнение документа по карте счетов из `РегистрБухгалтерии.Типовой` (период = год отчётной даты);
- проведение → `АиФ_ДвиженияМСФО`;
- помощник: предпросмотр консолидации + создание документов исключения ВГО;
- отчёт СКД `АиФ_КонсолидацияМСФО`.

Проверено COM-тестом: заполнение 7010, проведение, движение в регистре, таблица консолидации.

## Как пользоваться в базе

1. Раздел **«АиФ МСФО и консолидация»**.
2. Заполнить периметр / карту / правила ВГО (демо уже есть).
3. Документ **Корректировка МСФО** → организация → **Заполнить по карте счетов БП** → провести.
4. **Помощник консолидации** → период → показать консолидацию / создать документы ВГО.
5. Отчёт **Консолидация МСФО (АиФ)**.
